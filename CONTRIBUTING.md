# Contributing to TRACE

Thank you for your interest in contributing to **TRACE**!

## How to Contribute

1. **Fork the Repository**
2. **Create a Feature Branch**
   ```bash
   git checkout -b feature/amazing-feature
   ```
3. **Commit Your Changes**
   ```bash
   git commit -m "feat: add amazing feature"
   ```
4. **Push to Your Branch**
   ```bash
   git push origin feature/amazing-feature
   ```
5. **Open a Pull Request**

## Code Guidelines

- Run `npm run typecheck` to ensure no TypeScript compilation errors.
- Ensure all components preserve accessibility and semantic HTML.
- Follow the design system tokens and styling conventions.
