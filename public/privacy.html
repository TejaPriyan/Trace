Privacy policy

How the website, local features and external services handle information.

Updated 27 October 2026

Submitted URLs and reports

A real trace sends the URL and crawl settings to the TRACE server. The server requests public pages from the destination website and builds an analysis report. Do not submit private links, tokens, account pages or information you are not permitted to analyze. Target websites receive requests from the crawler.

Reports and website metadata can be kept in server memory or a configured database. The code contains a seven-day database cleanup threshold, but this is not a guarantee of a fixed deletion time: execution and hosting configuration affect retention. Treat a report identifier as potentially shareable; do not rely on it to protect confidential content.

Your browser can store a theme, recent traces and cached reports under trace.theme, trace.recent and trace.report. keys in localStorage. Clear this site’s browser storage to remove those local copies. That does not delete a separate server-side report.

Hosting and external services

When you load a page, the hosting service receives technical request information such as your IP address, browser details and requested URL. Operational logs and retention depend on the hosting provider and deployment. The deployment’s hosting and any configured database provider handle operational request and report data. Core analysis currently selects the no-op AI provider and does not require an external model API. If that implementation changes, this notice must be updated before the new processing is enabled.

Advertising and choices

This site identifies its publisher to Google AdSense for site review. Verification metadata and ads.txt do not themselves load advertisements. The pages in this release do not include an AdSense ad-serving script.

If Google advertising is enabled on a page, Google and its partners may use cookies or similar identifiers, IP addresses and device or browser information to deliver and measure ads, including personalized ads where permitted. This is separate from any local processing performed by the tool. Read how Google uses information from sites and apps and manage personalization through My Ad Center.

Where required, advertising must be accompanied by an appropriate consent mechanism before it is activated. Browser settings can remove stored site data and control cookies. Following an external link is governed by the destination service’s policy.

Questions and updates

Use the Contact page for questions about this site’s handling of information. Please describe the page and action involved. This notice should be updated whenever the site’s data processing or advertising configuration changes.
