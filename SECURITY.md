# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within TRACE, please send an e-mail to **Teja Priyan** at [teja1616150@gmail.com](mailto:teja1616150@gmail.com).

Please include:
- A description of the vulnerability and its potential impact.
- Steps to reproduce or a proof of concept.

We appreciate your responsible disclosure and will respond promptly to verify and address the issue.
